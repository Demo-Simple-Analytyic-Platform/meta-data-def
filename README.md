# Meta Data Definitions (Model)

This project/repository is part of the Meta-Data-Model and forms the framework for storing the meta data definition of a Model. The ***Geting started*** can be found in the `Meta-Data-Model-part ([here](https://github.com/Demo-Simple-Analytyic-Platform/meta-data-model) you can find the repository) that contains the logic for deployment and data processing.

This Repository forms the template from which `your`-version for `your`-models can be copied. The [README](https://github.com/Demo-Simple-Analytyic-Platform/meta-data-model/blob/main/README.md) in the `meta-data-model`-repository will help you get started and the [tutorials](https://github.com/Demo-Simple-Analytyic-Platform/meta-data-model/blob/main/README.md#tutorial) will help you start working with the tooling.
